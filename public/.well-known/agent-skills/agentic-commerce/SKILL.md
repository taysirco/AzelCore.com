# AzelCore Commerce Protocols (بروتوكولات التجارة)

Agentic commerce discovery for AzelCore via UCP and ACP protocols.
اكتشاف التجارة التلقائية (Agentic Commerce) لخدمات عزل كور عبر بروتوكولات UCP و ACP.

## What This Does (ماذا يفعل هذا السجل؟)

AzelCore publishes commerce discovery documents for AI agents:
تنشر AzelCore مستندات لاكتشاف الخدمات لعملاء الذكاء الاصطناعي:
- **UCP** (Universal Commerce Protocol): `/.well-known/ucp`
- **ACP** (Agentic Commerce Protocol): `/.well-known/acp.json`
