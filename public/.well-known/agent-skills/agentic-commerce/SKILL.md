# AzelCore Commerce Protocols

Agentic commerce discovery for AzelCore via UCP and ACP protocols.

## What This Does

AzelCore publishes commerce discovery documents for AI agents:
- **UCP** (Universal Commerce Protocol): `/.well-known/ucp`
- **ACP** (Agentic Commerce Protocol): `/.well-known/acp.json`
